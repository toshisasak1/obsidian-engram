- What you don't write back disappears. What you write back compounds.

- Record what was corrected and why in `_kb/decisions/`
- Items marked with a warning emoji in `_kb/sessions/` are unverified — confirm with the user before acting
- AI-generated analysis is a hypothesis. Never overwrite existing strategy documents without explicit user approval
