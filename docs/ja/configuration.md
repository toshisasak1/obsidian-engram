# 設定リファレンス

Engram の全設定は `.engram/config.toml` に集約されます。このファイルは `engram init` で自動生成され、自由に編集できます。

## 設定の解決順序

Engram は以下の順序で設定を解決します。後の層が前の層を上書きします:

1. **ビルトインデフォルト** -- データクラスのデフォルト値と自動検出されたソース
2. **グローバル設定** -- `~/.config/engram/config.toml` (Linux/macOS) または `%APPDATA%/engram/config.toml` (Windows)
3. **プロジェクト設定** -- `<vault>/.engram/config.toml`
4. **環境変数** -- `ENGRAM_DB_PATH`, `ENGRAM_VAULT_PATH`, `ENGRAM_EMBEDDING_API_KEY`
5. **CLI フラグ** -- コマンドラインオプション

グローバル設定とプロジェクト設定の両方が存在する場合、深いマージ(再帰的な辞書マージ)が行われます。dict 値は再帰的にマージされ、それ以外の値は上書きされます。

## 設定ファイルの完全例

```toml
# Engram configuration
# https://github.com/toshisasak1/obsidian-engram
#
# This file was auto-generated by `engram init`.
# Edit freely -- comments are preserved on re-generation.

# Path to the SQLite database (relative to vault root).
db_path = ".engram/engram.db"

# Absolute path to the Obsidian vault root.
vault_path = "/home/you/my-vault"

# AI tool sources to index.
# Each [sources.<name>] section defines one tool.

[sources.claude]
enabled = true
path = "/home/you/.claude/projects"
parser = "claude"

[sources.codex]
enabled = true
path = "/home/you/.codex"
parser = "codex"

[sources.gemini]
enabled = true
path = "/home/you/.gemini"
parser = "gemini"

# Hybrid search tuning.
[search]
fts_limit_multiplier = 5
vector_limit_multiplier = 5
rrf_k = 60
half_life_days = 30.0

# Embedding backend.  Set enabled = true and choose a provider
# ("local", "openai", "voyage", "none").
[embedding]
enabled = false
provider = "local"
model = "all-MiniLM-L6-v2"
batch_size = 16
max_characters = 4000
# api_key = ""  # Or set ENGRAM_EMBEDDING_API_KEY env var.

# File-system watcher / poll settings.
[sync]
poll_interval_seconds = 30
settle_seconds = 8

# Auto-tagging. Assign tags to entries for filtered search.
# provider: "keyword" (rule-based), "cli" (claude/codex), "both".
[tagging]
enabled = false
provider = "keyword"
batch_size = 50
max_tags = 5

[tagging.cli]
command = "claude"
timeout = 120

# [tagging.rules]
# python = ["python", "pip", "venv", "pytest"]
# trading = ["forex", "gmma", "ema", "bot", "backtest"]

# Obsidian vault knowledge ingestion.
[vault_knowledge]
enabled = true
include = ["**/*.md"]
exclude = ["**/node_modules/**", "**/.obsidian/**", "**/.engram/**", "**/.smart-env/**", "**/.git/**"]
```

## トップレベル設定

### `db_path`

- **型**: 文字列 (パス)
- **デフォルト**: `".engram/engram.db"`
- **説明**: SQLite データベースファイルのパス。Vault ルートからの相対パスまたは絶対パス。

```toml
db_path = ".engram/engram.db"
```

相対パスは Vault ルート(または `engram init` を実行したディレクトリ)を基準に解決されます。

### `vault_path`

- **型**: 文字列 (パス) またはなし
- **デフォルト**: なし (自動検出)
- **説明**: Obsidian Vault のルートディレクトリへの絶対パス。

```toml
vault_path = "/home/you/my-vault"
```

通常は `engram init` 時に自動設定されます。Vault 内で CLI を実行する場合は省略可能で、カレントディレクトリから `.obsidian/` または `.engram/` を検索して自動検出します。

## `[sources.<name>]` -- AIツールソース

各 AI ツールをサブセクションとして定義します。`<name>` はソースの識別子です。

### 組み込みソース名

| 名前 | パーサー | デフォルトパス |
|------|---------|---------------|
| `claude` | ClaudeParser | `~/.claude/projects` |
| `codex` | CodexParser | `~/.codex` |
| `gemini` | GeminiParser | `~/.gemini` (内部で `antigravity/brain` を探索) |

### 設定項目

#### `enabled`

- **型**: ブール値
- **デフォルト**: `true`
- **説明**: このソースを同期対象にするかどうか。

```toml
[sources.claude]
enabled = false  # Claude のログを一時的に無効化
```

#### `path`

- **型**: 文字列 (パス)
- **デフォルト**: `""` (自動検出)
- **説明**: ソースファイルのルートディレクトリへのパス。空の場合はパーサーのデフォルトパスが使用されます。

```toml
[sources.claude]
path = "/custom/path/to/claude/projects"
```

チルダ展開 (`~`) はサポートされていません。絶対パスを使用してください。

#### `parser`

- **型**: 文字列
- **デフォルト**: `""` (ソース名と同じ)
- **説明**: 使用するパーサーの名前。通常はソース名と一致するため省略可能。カスタムパーサーを使う場合に指定します。

```toml
[sources.my_tool]
enabled = true
path = "/path/to/my-tool/logs"
parser = "claude"  # Claude と同じ JSONL 形式なので claude パーサーを流用
```

### カスタムソースの追加

任意の名前でソースを追加できます:

```toml
[sources.aider]
enabled = true
path = "/home/you/.aider/sessions"
parser = "aider"  # entry_points で登録されたカスタムパーサー
```

パーサーが組み込みにもプラグインにも見つからない場合、同期時にエラーが出力されてスキップされます。

## `[search]` -- 検索チューニング

ハイブリッド検索のパラメータを調整します。

### `fts_limit_multiplier`

- **型**: 整数
- **デフォルト**: `5`
- **説明**: FTS5 検索で取得する候補数の倍率。最終的な結果数 (`limit`) に対してこの倍率分の候補を FTS5 から取得し、RRF 統合の入力とします。

```toml
[search]
fts_limit_multiplier = 10  # limit=10 なら FTS5 から 100 件取得
```

大きくすると FTS5 の候補が増え、RRF 統合の精度が上がりますが、検索は遅くなります。

### `vector_limit_multiplier`

- **型**: 整数
- **デフォルト**: `5`
- **説明**: ベクトル検索で取得する候補数の倍率。

```toml
[search]
vector_limit_multiplier = 5
```

### `rrf_k`

- **型**: 整数
- **デフォルト**: `60`
- **説明**: Reciprocal Rank Fusion の定数 K。`score = 1 / (K + rank)` の計算に使用されます。

```toml
[search]
rrf_k = 60
```

- **値が小さい** (例: 10): 上位ランクの結果に重みが集中。1位と2位のスコア差が大きくなる。
- **値が大きい** (例: 100): ランク間のスコア差が小さくなり、FTS とベクトルの結果が滑らかにブレンドされる。

### `half_life_days`

- **型**: 浮動小数点数
- **デフォルト**: `30.0`
- **説明**: 時間減衰の半減期(日数)。この日数が経過すると、スコアが半分に減衰します。

```toml
[search]
half_life_days = 14.0  # 2週間で半減 (最近の会話をより重視)
```

- **値が小さい** (例: 7.0): 最近の会話を強く優先。古い会話は急速に沈降。
- **値が大きい** (例: 90.0): 古い会話も比較的高いスコアを維持。ナレッジベース的な使い方に適する。
- **`0` 以下**: 時間減衰なし (全てのエントリが同等の重み)。

## `[embedding]` -- ベクトル埋め込み

セマンティック検索(意味的類似性)のためのベクトル埋め込み設定です。

### `enabled`

- **型**: ブール値
- **デフォルト**: `false`
- **説明**: ベクトル埋め込みを有効にするかどうか。

```toml
[embedding]
enabled = true
```

有効化すると、`engram sync` 時にテキストのベクトル化が行われ、検索時に FTS5 とベクトルの両方が使用されます。

### `provider`

- **型**: 文字列
- **デフォルト**: `"local"`
- **説明**: 埋め込みプロバイダー。

| 値 | 説明 | 追加依存 |
|----|------|---------|
| `"local"` | sentence-transformers でローカル実行 | `pip install obsidian-engram[embeddings]` |
| `"openai"` | OpenAI Embeddings API | `pip install obsidian-engram[openai]` + APIキー |
| `"voyage"` | Voyage AI Embeddings API | `pip install obsidian-engram[openai]` + APIキー |
| `"none"` | 埋め込み無効 (enabled=true でも実行しない) | なし |

### `model`

- **型**: 文字列
- **デフォルト**: `"all-MiniLM-L6-v2"`
- **説明**: 埋め込みモデルの名前。

```toml
[embedding]
# ローカルモデルの例
model = "all-MiniLM-L6-v2"         # 384次元, 約80MB, 高速
# model = "paraphrase-multilingual-MiniLM-L12-v2"  # 384次元, 多言語対応

# OpenAI API の例
# model = "text-embedding-3-small"  # 1536次元
# model = "text-embedding-3-large"  # 3072次元

# Voyage API の例
# model = "voyage-3"                # 1024次元
```

ローカルモデルは sentence-transformers のモデル名を指定します。初回実行時に Hugging Face Hub からダウンロードされます。

### `batch_size`

- **型**: 整数
- **デフォルト**: `16`
- **説明**: 一度に埋め込みを計算するテキストの数。

```toml
[embedding]
batch_size = 32  # GPUがある場合は大きくできる
```

### `max_characters`

- **型**: 整数
- **デフォルト**: `4000`
- **説明**: 埋め込み計算時にテキストを切り詰める最大文字数。

```toml
[embedding]
max_characters = 8000  # 長いテキストもより多く取り込む
```

### `api_key`

- **型**: 文字列
- **デフォルト**: `""`
- **説明**: OpenAI / Voyage API のキー。環境変数 `ENGRAM_EMBEDDING_API_KEY` でも設定可能。

```toml
[embedding]
# config.toml に直書きは非推奨。環境変数を推奨。
# api_key = "sk-..."
```

環境変数の方が安全です:

```bash
export ENGRAM_EMBEDDING_API_KEY="sk-..."
```

## `[sync]` -- 同期設定

ファイルシステムの監視とポーリングの設定です。

### `poll_interval_seconds`

- **型**: 整数
- **デフォルト**: `30`
- **説明**: `engram watch` のポーリング間隔(秒)。

```toml
[sync]
poll_interval_seconds = 60  # 1分間隔に変更
```

### `settle_seconds`

- **型**: 整数
- **デフォルト**: `8`
- **説明**: ファイルの最終更新からこの秒数が経過するまで同期をスキップします。エディタの書き込み完了を待つためのバッファです。

```toml
[sync]
settle_seconds = 3  # 高速なファイルシステムでは短くできる
```

## `[tagging]` -- 自動タグ付け

エントリに自動的にタグを付与する機能の設定です。詳細は[自動タグ付け](./tagging.md)を参照してください。

### `enabled`

- **型**: ブール値
- **デフォルト**: `false`
- **説明**: タグ付け機能を有効にするかどうか。

### `provider`

- **型**: 文字列
- **デフォルト**: `"keyword"`
- **説明**: タグ付けバックエンド。

| 値 | 説明 |
|----|------|
| `"keyword"` | ルールベースのパターンマッチング (無料、即座) |
| `"cli"` | `claude -p` / `codex -q` によるAIタグ付け (アカウント課金のみ) |
| `"both"` | keyword を先に実行し、cli で追加タグを付与 |

### `batch_size`

- **型**: 整数
- **デフォルト**: `50`
- **説明**: 1回の実行で処理する最大エントリ数。

### `max_tags`

- **型**: 整数
- **デフォルト**: `5`
- **説明**: エントリあたりの最大タグ数。

### `[tagging.cli]`

CLI バックエンドの設定:

```toml
[tagging.cli]
command = "claude"   # "claude" または "codex"
timeout = 120        # バッチあたりのタイムアウト(秒)
```

### `[tagging.rules]`

カスタムキーワードルール。キーの名前がタグ名、値がマッチするキーワードの配列です:

```toml
[tagging.rules]
python = ["python", "pip", "venv", "pytest"]
trading = ["forex", "gmma", "ema", "bot", "backtest"]
```

## `[vault_knowledge]` -- Vault ナレッジ取込

Obsidian Vault 内の Markdown ファイルをインデックスする設定です。

### `enabled`

- **型**: ブール値
- **デフォルト**: `true`
- **説明**: Vault の Markdown ファイルを検索対象に含めるかどうか。

```toml
[vault_knowledge]
enabled = true
```

### `include`

- **型**: 文字列の配列 (glob パターン)
- **デフォルト**: `["**/*.md"]`
- **説明**: インデックスに含めるファイルのパターン。

```toml
[vault_knowledge]
include = ["**/*.md", "**/*.txt"]  # Markdown と テキストファイル
```

### `exclude`

- **型**: 文字列の配列 (glob パターン)
- **デフォルト**: `["**/node_modules/**", "**/.obsidian/**", "**/.engram/**", "**/.smart-env/**", "**/.git/**"]`
- **説明**: インデックスから除外するパスのパターン。

```toml
[vault_knowledge]
exclude = [
  "**/node_modules/**",
  "**/.obsidian/**",
  "**/.engram/**",
  "**/.smart-env/**",
  "**/.git/**",
  "**/archive/**",       # アーカイブフォルダを除外
  "**/drafts/**",        # 下書きフォルダを除外
]
```

Vault パーサーは以下のディレクトリ名を常にスキップします(ハードコード): `.obsidian`, `.git`, `.trash`, `node_modules`, `__pycache__`

## 環境変数

設定ファイルの値を環境変数で上書きできます。環境変数は最も優先度が高く、config.toml の値よりも優先されます。

| 環境変数 | 上書き対象 | 例 |
|---------|-----------|-----|
| `ENGRAM_DB_PATH` | `db_path` | `/tmp/engram-test.db` |
| `ENGRAM_VAULT_PATH` | `vault_path` | `/home/you/my-vault` |
| `ENGRAM_EMBEDDING_API_KEY` | `embedding.api_key` | `sk-...` |

使用例:

```bash
# テスト用にデータベースパスを一時変更
ENGRAM_DB_PATH=/tmp/test.db engram search "テスト"

# CI 環境でのAPIキー設定
export ENGRAM_EMBEDDING_API_KEY="sk-proj-xxxxx"
engram sync
```

## グローバル設定

全プロジェクト共通の設定をグローバル設定ファイルに記述できます:

- **Linux / macOS**: `~/.config/engram/config.toml`
- **Windows**: `%APPDATA%\engram\config.toml`

グローバル設定はプロジェクト設定の前に読み込まれ、プロジェクト設定で上書きできます。全プロジェクトで共通のエンベディング設定や、共通の除外パターンなどを記述するのに便利です。

```toml
# ~/.config/engram/config.toml (グローバル設定の例)

[embedding]
enabled = true
provider = "local"
model = "all-MiniLM-L6-v2"

[search]
half_life_days = 14.0

[vault_knowledge]
exclude = [
  "**/node_modules/**",
  "**/.obsidian/**",
  "**/.engram/**",
  "**/.git/**",
  "**/archive/**",
]
```

## ヒントと推奨設定

### 日本語メインの場合

FTS5 の trigram トークナイザは日本語をそのまま処理できるため、特別な設定は不要です。ただし、セマンティック検索を有効にする場合は多言語モデルの使用を検討してください:

```toml
[embedding]
enabled = true
provider = "local"
model = "paraphrase-multilingual-MiniLM-L12-v2"
```

### 大量のファイルがある Vault

数千ファイルの Vault では、初回同期に時間がかかる場合があります。不要なディレクトリを除外して高速化します:

```toml
[vault_knowledge]
exclude = [
  "**/node_modules/**",
  "**/.obsidian/**",
  "**/.engram/**",
  "**/.git/**",
  "**/attachments/**",
  "**/templates/**",
  "**/.trash/**",
]
```

### 最近の会話を重視

```toml
[search]
half_life_days = 7.0  # 1週間で半減
```

### ナレッジベースとして使用 (時間減衰を弱める)

```toml
[search]
half_life_days = 365.0  # 1年で半減 (ほぼ時間に依存しない)
```
